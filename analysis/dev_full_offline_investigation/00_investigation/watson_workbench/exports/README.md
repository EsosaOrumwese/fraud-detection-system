# Watson Workbench Exports

Generated figures and derived tables are grouped by investigation topic so the export root stays navigable.

- `transaction_schema_merchant_ids/`: merchant seed universe checks, country concentration tables, and channel/MCC follow-ups.
- `gdp_bucket_map/`: GDP surface, frozen bucket map, and bucket-compression views.
- `merchant_allocation_policy/`: merchant allocation policy counterfactuals and implementation-artifact views.
- `hurdle_priors/`: hurdle prior authoring and synthetic-world explainability figures.
- `hurdle_coefficients/`: hurdle coefficient bundle, training fit, lineage, and runtime scoring figures.
