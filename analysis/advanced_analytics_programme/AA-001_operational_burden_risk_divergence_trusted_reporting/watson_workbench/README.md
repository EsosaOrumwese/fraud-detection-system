# AA-001 Watson Workbench

This folder is Watson's working area for `AA-001`.

It is separate from the formal project delivery pack. The purpose is to hold investigation notes, scratch SQL, compact profiling extracts, draft figures, and intermediate reasoning before anything is promoted into the official execution outputs.

## Folder Roles

| Folder | Purpose |
|---|---|
| `notes` | Working investigation notes and reasoning trails. |
| `sql` | Scratch or prototype SQL used to test joins, metrics, and QA logic. |
| `extracts` | Compact derived summaries used for investigation. Do not place large raw data here. |
| `figures` | Draft visual evidence produced during workbench analysis. |
| `scratch` | Temporary local working material that should not be treated as delivery evidence. |

## Promotion Rule

Nothing in this workbench is stakeholder-ready by default.

Material should only be promoted into `execution/` or the formal planning/reporting docs after it has been reviewed, reconciled, and accepted as part of the delivery flow.
