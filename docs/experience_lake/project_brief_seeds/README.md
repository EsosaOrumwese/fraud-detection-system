# Project Brief Seeds

This folder holds cross-project brief seeds for portfolio projects that should later live in their own repositories.

These files are not execution artifacts for the fraud decisioning platform. They exist so that a future agent, model, or repo starts with the correct expectations, scope, standards, and evidence target instead of treating each project as a generic coursework rewrite.

## Handoff Rule

When starting a new repo for one of these projects, copy the relevant brief into that repo as the project anchor, then rebuild the project from the brief rather than from old coursework artifacts.

The old coursework may inform the starting point, but the new work must be planned and executed as a professional analytical project.
