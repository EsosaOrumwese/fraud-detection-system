# Frasers Group — Payments Data Analyst: 3 Screens

## 1. Business / problem screen

Frasers is not primarily hiring a fraud investigator in the Trustpilot sense or a revenue-protection analyst in the Arriva sense. This role sits inside **Digital Risk** and focuses on **eCommerce payments and fraud performance**. The analyst supports reporting and analysis across payment performance, payment costs, fraud, chargebacks, and operational metrics for fraud and payments teams. 

So the CV must prove evidence around:

| Frasers business problem    | What the CV needs to show                                                                                 |
| --------------------------- | --------------------------------------------------------------------------------------------------------- |
| Payment performance         | You can analyse payment success, declines, authorisations, checkout friction, or payment journey issues   |
| Payment costs               | You can track cost movements, payment provider costs, transaction costs, or cost drivers                  |
| Fraud trends                | You can identify fraud patterns, risky behaviour, anomalies, or suspicious transaction/account activity   |
| Chargebacks                 | You can analyse chargeback trends, root causes, rates, volumes, or financial impact                       |
| Operational metrics         | You can maintain reporting for fraud, payments, finance, eCommerce, or digital risk teams                 |
| Unexpected data movements   | You can investigate sudden changes in metrics and explain root causes                                     |
| Checkout experience         | You can connect analysis to smoother customer checkout, fewer declines, or more reliable payment journeys |
| Commercial decision support | You can turn accurate analytics into day-to-day operational and longer-term commercial decisions          |

The strongest business-positioning phrase for Frasers is:

```text
payments, fraud and chargeback analytics for eCommerce risk and checkout performance
```

Not:

```text
fraud modelling and customer behaviour ML
```

That Tesco-style framing is too ML-heavy for this role. Frasers wants a practical payments/fraud analyst who can maintain reports, investigate movement in metrics, and support Digital Risk, Finance and eCommerce decisions.

---

## 2. Technical / capability screen

Frasers is very concrete about tools and artefacts. They ask for Excel, SQL, structured datasets such as **BigQuery**, and exposure to BI tools such as **Power BI, Looker/Data Studio or Tableau**. They also mention lookups, index/match, pivot tables and data manipulation in Excel. 

Because you have used **SQL, BigQuery, Looker, Power BI, Excel and VBA**, we should state those tools directly where they are relevant.

| Technical requirement           | Concrete evidence to look for                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Excel                           | Excel payment reconciliation workbook, Excel chargeback tracker, pivot-table fraud summary, lookup/index-match payment analysis |
| SQL                             | SQL payment performance query, SQL fraud trend query, SQL chargeback query, SQL root-cause query                                |
| BigQuery                        | BigQuery payment dataset query, BigQuery chargeback trend query, BigQuery fraud performance table                               |
| Power BI                        | Power BI payment performance dashboard, Power BI fraud/chargeback dashboard, Power BI operational metrics report                |
| Looker                          | Looker payment dashboard, Looker fraud trend report, Looker chargeback performance view                                         |
| VBA                             | VBA reconciliation macro, VBA exception-flagging workbook, VBA report refresh macro                                             |
| Reporting/dashboard maintenance | Validated weekly/monthly payment dashboard, maintained chargeback trend report, refreshed operational metrics pack              |
| Root-cause analysis             | Decline-rate root-cause report, chargeback spike analysis, fraud trend investigation, payment-provider issue analysis           |
| Data monitoring                 | Payment acceptance monitor, chargeback rate monitor, fraud metric tracker, operational metric dashboard                         |

For Frasers, **dashboards and reports are not supporting evidence — they are central evidence**. The ad explicitly says the role will produce, validate and maintain reporting and dashboards covering payment performance, costs, fraud and chargebacks. 

So our eventual CV language should name things like:

```text
BigQuery chargeback trend query
Power BI payment performance dashboard
Looker fraud performance report
Excel payment reconciliation workbook
VBA exception-flagging macro
decline-rate root-cause report
chargeback spike analysis
```

Not vague phrases like “data reporting” or “BI analysis.”

## 3. Working-style / stakeholder screen

Frasers wants someone early in their data career but proactive, accurate, structured, commercially aware, and able to work with Digital Risk, Finance, eCommerce and sometimes external payment partners. The ad also says the role may involve a technical presentation/task during the interview process. 

| Working-style requirement  | CV evidence we should look for                                                                               |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| High attention to detail   | Excel reconciliation workbook, dashboard validation checks, chargeback data-quality checks                   |
| Structured problem solving | Root-cause report for payment decline spike, chargeback movement analysis, fraud trend investigation         |
| Proactive ownership        | Maintained recurring dashboard, built exception tracker, owned refresh/validation process                    |
| Independent + team working | Responded to Digital Risk, Finance or eCommerce ad-hoc requests while maintaining recurring reports          |
| Commercial awareness       | Linked analysis to payment acceptance, cost, chargebacks, fraud prevention or checkout reliability           |
| Stakeholder collaboration  | Produced reports for Digital Risk, Finance, eCommerce, fraud team, payments team or external payment partner |
| Data governance awareness  | Handled customer/payment/fraud data carefully, documented data checks, controlled report definitions         |
| Clear communication        | Payment performance memo, chargeback root-cause summary, dashboard commentary, stakeholder recommendation    |

The working-style story should be:

```text
I can maintain accurate Excel/SQL/BigQuery/Power BI/Looker reporting for payments and fraud, investigate metric movements, and explain what payment, fraud or chargeback trends mean for Digital Risk, Finance and eCommerce decisions.
```
