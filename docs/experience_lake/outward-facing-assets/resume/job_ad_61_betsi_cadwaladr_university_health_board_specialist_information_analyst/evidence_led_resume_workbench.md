# Biggest gaps to solve before writing

1. **NHS Data Dictionary / NHS information codes**  
   This is the biggest formal gap. We need decide whether Eric has done any learning, coursework, research, mini-project or NHS dataset review around NHS definitions, RTT, MHSDS, ICD, OPCS, SNOMED CT, NHS Data Model and Dictionary, or Welsh NHS reporting.

2. **National Minimum Datasets / mental health datasets**  
   For this role, the likely relevant area is mental health reporting. We need see if Eric can build a small claim-bearing project or learning note around **Mental Health Services Data Set**, referral pathways, waiting times, caseloads, activity, outcomes, data quality and reporting definitions.

3. **Access**  
   They specifically name Excel, Power BI and Access. We have Excel and Power BI. Need confirm Microsoft Access. If not, do not claim it.

4. **SPC, confidence intervals and ANOVA**  
   Eric can claim statistical knowledge from MSc, but we need concrete examples or learning evidence using SPC and confidence intervals. The South Western QHSE story covers standard deviation and trend analysis well, but SPC needs sharpening.

5. **Pathway analysis and GIS**  
   Not essential in the person spec, but strong JD themes. Need decide if we add a small healthcare-adjacent project or keep it as transferable sequence/path analysis from platform/thesis.

6. **EHR transformation readiness**  
   This is central in the advert. We need interview Eric on platform migration/reporting-readiness: how he prepares reporting when the underlying data system changes.

# Supporting Statement Plan

For this role, the statement should be **person-spec led**, not a broad story. The sift panel will likely mark the application against the essential criteria in the person specification, while the job advert tells us the context: **mental health data, reports/dashboards, stakeholder support, SQL/analytical tools, trend/performance analysis, data quality, and reporting readiness for a new EHR**.

## Recommended Statement Plan

Aim for **1,200-1,400 words** if the NHS supporting statement box allows it. This is broad Band 6 criteria, so 800 words would likely under-cover the person spec. But we should still avoid a long evidence dump.

The statement should make this argument:

> I am a strong fit for this Specialist Information Analyst role because I combine postgraduate statistical/data science training, practical operational analytics experience, advanced Excel/Access/Power BI/SQL/Python/SAS/Oracle evidence, data-quality and reporting discipline, stakeholder communication, and targeted preparation for NHS information standards, mental-health reporting concepts, Data Protection, FOI and EHR reporting readiness.
