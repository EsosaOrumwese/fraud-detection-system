# Sainsbury’s — 3 Screens

## 1. Business / problem screen

This role sits in **Food Commercial / Grocery & GM**. The business problem is not “data modelling” as the centre, and it is not “fraud/payments.” It is **commercial performance**: using data to understand how products, deals, events and secondary space are performing, then turning that into recommendations.

The job ad specifically points to **secondary space performance**, **secondary space allocation strategy**, **deal effectiveness**, **event performance**, **commercial recommendations**, and **opportunities for improvement**. 

So the CV must eventually prove evidence around:

| Sainsbury’s business problem    | What the CV needs to show later                                                                          |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Secondary space performance     | You can analyse how a placement, segment, channel, area, group, or category performs against a baseline. |
| Space allocation-style analysis | You can compare options and recommend where effort/resources should go.                                  |
| Deal effectiveness              | You can evaluate whether an intervention, offer, campaign, event, or action worked.                      |
| Event performance               | You can analyse performance before/during/after a defined event period.                                  |
| Commercial KPI movement         | You can explain why sales, uptake, conversion, demand, performance, cost, or activity changed.           |
| Opportunity identification      | You can find underperforming areas, high-performing segments, or improvement levers.                     |
| Tangible recommendations        | You can turn analysis into a specific recommendation, not just “insight.”                                |

The strongest business-positioning phrase is probably:

```text
commercial performance analysis across KPIs, events, allocation decisions and improvement opportunities
```

But in the CV we need to make that concrete through artefacts like:

```text
Power BI KPI dashboard
Excel performance tracker
SQL performance query
event performance report
deal effectiveness analysis
allocation comparison table
variance analysis
recommendation memo
```

## 2. Technical / capability screen

This job ad is less tool-specific than Nando’s. It does **not** name SQL, BigQuery, Looker, Power BI or Excel in the pasted source. Instead, it screens for the capability to build **advanced tools and reports**, use **rich and varied data**, create **new sources of insight**, perform **ad-hoc and deep-dive analyses**, use **statistical analysis and data visualisation**, and **automate processes**. 

So the technical screen is:

| Technical requirement         | Concrete evidence to look for later                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------ |
| Advanced tools and reports    | Power BI dashboard, Excel tracker, SQL query pack, Looker report, automated report workbook.     |
| Commercial KPI reporting      | KPI dashboard, weekly/monthly performance report, variance table, category performance tracker.  |
| Data integration              | Joined datasets, combined data sources, SQL/BigQuery tables, Excel/Power BI model.               |
| Ad-hoc and deep-dive analysis | One-off investigation, root-cause report, event deep dive, underperformance analysis.            |
| Statistical analysis          | Baseline comparison, variance analysis, trend analysis, uplift analysis, before/after analysis.  |
| Data visualisation            | Power BI dashboard, visual trend report, KPI charts, performance comparison visuals.             |
| Automation                    | VBA macro, automated refresh, reusable reporting template, recurring data-quality checks.        |
| Report robustness             | Validation checks, reconciliation, error reduction, refresh reliability, documented assumptions. |

The CV should not just say:

```text
data visualisation
advanced analytics
commercial insight
```

It needs objects:

```text
Power BI dashboard tracking 9 KPIs
Excel performance tracker with pivot tables and lookups
SQL variance query across 12 reporting periods
visual trend report with 3 recommendations
VBA macro cutting review time from 45 to 25 minutes
```

## 3. Working-style / stakeholder screen

Sainsbury’s wants someone who can work at pace, collaborate with other data and analytics teams, communicate to cross-functional teams, present complex analysis to non-technical stakeholders, and continuously improve report usefulness. 

So the working-style screen is:

| Working-style requirement      | Concrete evidence to look for later                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| Commercial curiosity           | Analysis that asked “why did this KPI move?” or “which option performed better?”            |
| Work at pace / deadlines       | Weekly report, recurring dashboard, deadline-led analysis, fast turnaround request.         |
| Cross-functional collaboration | Outputs for operations, finance, commercial, product, managers, supervisors, or data teams. |
| Non-technical communication    | Visual report, recommendation memo, dashboard commentary, plain-English summary.            |
| Feedback and robustness        | Revised report, validation checks, metric definitions, reduced reporting errors.            |
| Recommendation ownership       | Specific recommendation count, comparison table, ranked options, decision summary.          |
| Continuous improvement         | Automation, report refresh macro, improved dashboard reliability, fewer manual checks.      |

The working-style story should become:

```text
I can build KPI tools and reports, analyse performance movements, explain the drivers, and give managers a concrete recommendation under commercial deadlines.
```
