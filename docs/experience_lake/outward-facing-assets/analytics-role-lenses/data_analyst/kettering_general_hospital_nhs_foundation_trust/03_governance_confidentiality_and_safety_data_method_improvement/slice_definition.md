## 1. Requirement Being Targeted

The requirement being targeted here is the Kettering `UHN Patient Safety Data Analyst` expectation around:
- championing best practices for data governance
- championing best practices for confidentiality
- working within Trust guidelines for record keeping, data collection, safeguarding, confidentiality, and health and safety
- carrying out targeted audits and compliance reviews for `sepsis`, `AKI`, and `VTE`
- improving data-collection tools and methods so patient-safety analysis becomes more reliable and useful over time

This maps directly to the candidate-profile requirement that the analyst should be able to sound like someone who:
- treats governance, confidentiality, and data quality as part of the analytical job rather than an afterthought
- can validate safety data and judge whether it is fit for use
- can improve collection methods and analytical reliability over time
- can work within healthcare data-handling expectations without pretending to be the whole governance function

This note exists because that requirement is easy to flatten into the vague statement:
`good at governance and data quality`

That is not the real burden.

The employer is asking for something sharper:
- audit-safe patient-safety data handling
- confidentiality and governed release discipline
- targeted compliance-review support
- improvement of safety-data tools and methods
