## 1. Requirement Being Targeted

The requirement being targeted here is the Guy's and St Thomas' `R&D Data Analyst` expectation around:
- integrating content from multiple data sources
- analysing content from multiple data sources to provide timely information for internal decision-making
- analysing complex trends involving multiple streams of data
- forecasting implications in the short term
- forecasting implications in the long term
- using own judgement to decide when data is fit for purpose for analysis
- working within clear, accurate, and timely criteria for data use

This maps directly to the candidate-profile requirement that the analyst should be able to sound like someone who:
- can combine multiple operational and reporting sources into one usable analytical picture
- can interpret research-performance trends rather than only reproduce reporting surfaces
- can make bounded forward-looking judgements from controlled evidence
- can decide when the resulting data is strong enough to use for analysis and reporting

This note exists because that requirement is easy to flatten into the vague statement:
`good at analysis and forecasting`

That is not the real burden.

The employer is asking for something sharper:
- multi-source integration
- complex trend interpretation
- short- and long-term implication reading
- fit-for-purpose judgement over high-accountability data
